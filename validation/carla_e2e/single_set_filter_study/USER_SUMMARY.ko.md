# 사용자 기준으로 정리한 한 세트 결과

## 평가 기준
입력은 한 녹화6,000프레임이다. 목표는 **이 구간이 끝나기 전에 실제 목표 차량4대가 각각 한 번 이상 최종 요청 후보에 포함되는가**다. 같은 차량의 모든 재등장을 따로 보존해야 한다는 조건은 사용자가 요구한 기준이 아니었다. 그 조건으로 추가 실험을 확대한 것은 해석 오류였고, 추가 테스트는 중단했다.

| 단계 | 최종 요청 후보 | 목표 차량 포함 |
|---|---:|---:|
| YOLO 후보 기준 | 8,167 | 4/4 |
| HSV 추가 | 317 | 4/4 |
| 대상별 중복 억제 추가 | 19 | 4/4 |
| 3관측 확인 추가 | 18 | 4/4 |

색상·중복 억제 적용으로 후보는8,167→19회(99.77% 감소), 목표 차량4대는 모두 포함됐다. 재등장16건 중14건이라는 수치는 별도 보조 지표이며, 차량 단위의 실패로 해석하지 않는다. 실험용26회 수정안은 이 차량 단위 목적에서는 기존19회 구성보다 나을 이유가 없어 채택하지 않는다. 운영 기본 경로는 이 추가 실험 동안 변경하지 않았다.

## 연속 확인을 제외한 판단
N3는 목표 차량 포함률4/4로 같고 후보를19→18회로1회 더 줄였다. 확인 지연p95는0.225→0.435초로 늘었다. 따라서 지연·구현 복잡도 대비 추가 이득이 작다는 이유로 N3를 제외하는 판단은 가능하다. 차량 누락 때문에 제외했다고 쓰면 이 세트의 결과와 다르다.

후보 수만 무조건 최소화하면 N7은12회·차량4/4여서 기존19회보다 적다. 그 대신 확인 지연p95는3.55초다. 연속 확인 전체가 효과 없거나19회가 모든 구성의 최소라는 주장은 하지 않는다. 최종 선택은 후보 수와 확인 지연을 함께 고려한 절충이다.

## 배치 비교
목표 색만 먼저 남긴 뒤 추적하는 배치는22회, 색상 라벨→추적→현재 색 선별→중복 억제는19회, 색상 없이 추적→현재 색 선별→중복 억제도19회였다. 모두 목표 차량4/4다. 기존 배치는 비교한 시간적 확인 없는 배치 중 최소와 동률이며, 유일한 최적 순서라고 주장하지 않는다.

## 30세트 평균과 대표 한 세트를 구분함
30세트 전체의 현재 구조 평균은6,000프레임당22.23회(합계667회)다. 검출 목표 차량은177/180이 최종 후보에 포함됐으므로 전체는 무손실이 아니다. 대표 한 세트의19회·4/4·99.77%와 섞어 쓰지 않는다. [왜30세트인지·조건별 차이·목표 차량 수](EXPERIMENT_CONTEXT.ko.md)에 표와 근거를 정리했다.

## 자소서 문장

아래 문장은30세트 전체 결과를 기준으로 정리했다. 평균22.2프레임과 확인 지연p95 약3배(0.2→0.6초)는 전체 집계값이며, 한 세트의19프레임·4/4대 결과와 구분한다.

> VLM 기반 차량 탐지 시스템에서 VLM에 전달할 프레임을 줄이기 위해 YOLO를 앞단에 배치하고, 색상 선별·중복 억제·연속 프레임 확인을 필터 후보로 검토했습니다. 환경과 차량 조건을 바꾼 30개 테스트 세트로 구성과 처리 순서를 비교했습니다. 연속 프레임 확인은 추가 절감 효과에 비해 확인 지연 p95가 약 3배로 늘고 목표 차량 누락이 증가해 제외했습니다. 배치 대안 중 목표 차량 포함과 전달량의 균형이 가장 좋았던 ‘YOLO → 색상 정보를 활용한 추적 → 목표 색 선별 → 중복 억제 → VLM’ 순서를 유지했으며, 6,000프레임당 평균 22.2프레임을 VLM 검증 후보로 선별했습니다.

실제VLM은 호출하지 않았다. 한 세트 수치와30세트 평균을 구분하며, 모든 영상·조건의 무손실을 보장하지 않는다. 현재 저장 자료는10Hz·600초다. 따라서6,000프레임은10분이며20분으로 바꾸어 표기하지 않는다.
