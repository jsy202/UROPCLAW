# 결과·범위·검증 기록

## 이번 푸시에서 한 일
기존30세트의CSV와manifest를 읽어 평균과 조건표를 작성했다. 새 영상 수집·YOLO추론·VLM·필터재생·로컬 테스트는 실행하지 않았다. Git의 변경 파일·공백·링크·업로드 범위 확인만 수행한다. 푸시하면 기존GitHub Actions 설정의push/PR 자동 검사가 실행될 수 있다.

## 이미 수행했던 단일 세트 보조 분석
고정 입력Town10HD_Opt_clear_v30_s101,한 녹화6,000프레임. 기존 개발 자료의 첫 조건을 사용했고 다른 녹화의 프레임을 입력하지 않았다. 모든6,000이미지의SHA256과JPEG시작·끝마커를 확인하고 해상도800×600을 표본 검사했다. 이미지-set 해시는 이전 자료의 해당세트 해시와 일치했다. 원본분석은 덮어쓰지 않았다.

보조 정책 회귀5개는 수정 전 실패·수정 후 통과했다. 추가 실험 중단 이전에 수행했던 호스트 전체 검사는158passed/1historicalskip/2기존경고였고,matplotlib/CARLA/torch가 없는Python3.10 최소 의존성 환경은158passed/1skip이었다. 이는 이미 수행한 기록이며 이번 정리를 위해 다시 실행하지 않았다.

읽기 전용 검토에서 actor·episode집합 대조와GT격리,한 입력 제한을 확인했다. 첫 출현1건과 재등장1건을 모두 재등장이라고 썼던 표현을 바로잡았다. 이후 사용자가 기준을 차량별최소한번도달로 명확히 해 보조26회 정책을 채택하지 않고 기존19회 구성을 유지했다.

## GitHub Actions를 사용한 이유
실험 호스트에 설치된 라이브러리가 숨은 의존성을 가릴 수 있어,호스트 밖의 깨끗한Python3.10 환경에서 재현성과 회귀를 확인하려 사용했다. push와PR마다 문법·전체단위테스트·Fake구성요소replay smoke를 자동화한다. 실제CARLA영상실험이나실제VLM을 실행하는workflow가 아니다.

이전push검사에서matplotlib누락으로2테스트가실패했고,필터설정import가그래프모듈을미리불러오는문제를수정했다. 수정후 [push](https://github.com/jsy202/UROPCLAW/actions/runs/42264974586)·[PR](https://github.com/jsy202/UROPCLAW/actions/runs/42264982739) 검사는모두통과했다. 이는해당수정커밋의관측결과이며,이번새푸시의성공을미리주장하지않는다.
