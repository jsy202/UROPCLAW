# 6,000프레임 단위 결과 정리

최종 기준은 **6,000프레임 구간 안에 목표 차량 각각이 최소 한 번 최종 후보에 포함되는가**다. 같은 차량의 모든 재등장을 보존해야 한다는 별도 조건과 구분한다. 새 실험·로컬 테스트는 추가로 실행하지 않았다.

## 결과를 섞지 않음

대표 한 세트는 맑은 낮·차량30대·목표4대·seed101이다. YOLO8,167→HSV317→중복 억제19회, 목표4/4대, 요청 감소99.77%다.

30세트는3환경×2밀도×5시드다. 현재 구조의 전체 평균은22.23회이고 검출 목표 차량은177/180이 최종 후보에 포함됐다. 이 전체 결과를 무손실이라고 쓰지 않는다. 한 세트와 전체 평균은 별도 표로 공개한다.

N3는 대표 한 세트에서19→18회로1회 추가 절감했지만 확인 지연p95가0.225→0.435초로 늘었다. 제외 이유는 요청 절감과 지연·복잡도의 절충이다. 기존 배치와late-HSV배치는19회로 동률이며 유일한 최적 순서라고 주장하지 않는다.

## 채택하지 않은 추가 분석의 보조 기록

아래 자료는 모든 재등장을 보존해야 한다고 요구를 과도하게 해석해 수행한 추가 실험의 기록이다. 실험용26회 수정안은 실제 차량 단위 목적에서 기존19회 구성보다 나을 이유가 없어 채택하지 않았다. 운영 기본 경로도 변경하지 않았다. 더 이상의 추가 실험은 중단했다.
